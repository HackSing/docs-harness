  ## P2 问题

  1. **`script_fingerprint_tolerant` 1MiB chunk 边界 CRLF 归一化错误**（`scripts/harness.py:436-456`）。pending `\r` 遇次 chunk 首字节 `\n` 时，代码丢弃 `\n` 却写入 `\r`，边界 CRLF 归一化为 `\r` 而非 `\n`。已用 >1MiB 构造文件复现：同一逻辑内容的 LF 与 CRLF 版本指纹不等，与 docstring「行尾转换不视为内容漂移」矛盾。当前受管文件（harness.py ~470KB、规则文件）均小于 1MiB，实际不可达，属潜在缺陷。修复：`pending_cr` 分支在剥掉前导 `\n` 后应 `digest.update(b"\n")` 而非 `b"\r"`。
