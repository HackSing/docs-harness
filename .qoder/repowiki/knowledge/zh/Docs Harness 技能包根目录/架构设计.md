根目录仅承载包的元信息（package.json、VERSION）与对外契约文档（README.md、SKILL.md、CHANGELOG.md），真正的实现集中在 scripts/harness.py 与 harness-home/rules/ 中；tests/test_harness.py 通过 npm test 驱动 unittest discover 执行。所有子模块（docs、evals、harness-home、scripts、tests）通过 package.json 的 files 白名单打包发布，CLI 入口唯一由 scripts/harness.py 提供，宿主只能通过该脚本与控制器交互，形成“单入口 CLI + 多领域子模块”的解耦结构。版本信息由独立的 VERSION 文件与 package.json 的 version 字段共同维护，SKILL.md metadata.version 与之保持一致，确保三处版本同步。
