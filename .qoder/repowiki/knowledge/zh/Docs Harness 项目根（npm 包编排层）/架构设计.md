根目录作为 docs-harness 私有 npm 包的发布边界，由 package.json 的 files 白名单将 scripts/harness.py、docs/、evals/、plan-templates/、tests/ 等子模块打包进同一产物；运行时所有可执行逻辑集中在 scripts/harness.py，其他子目录仅作为数据与契约被其消费，彼此不独立运行。tests/test_*.py 通过 unittest discover 自动发现，验证版本同步与 v2 直接模式行为，形成对 harness.py 行为的回归保障。npm test、npm run self-test、npm run pack:check 构成跨子模块的统一入口，使文档、评估与模板子模块在构建期与运行期均受同一 CLI 编排约束。
