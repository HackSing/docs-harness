本模块为纯文档型归档目录，按职责分为三层：`plans/` 存放按版本号（如 v1.7.3）或主题命名的方案设计文档，每个方案以背景数据、分级承诺、实施步骤、验收标准与安全边界构成固定结构；`reviews/` 存放对应方案的源码级交叉评审报告，采用“总体结论 + P0/P1/P2 问题清单 + 已验证无问题关键路径”的三段式格式；根 `README.md` 明确该目录被默认知识查询排除且不出现在 npm 发布包中，仅用于回答“当时为什么这样设计”。依赖方向单向：review 文件引用并裁决 plans 中的设计，二者均不反向依赖当前产品真源（`README.md`、`SKILL.md`、`docs/contracts.md`、`docs/architecture.md`、`docs/testing.md`、`docs/plans/docs-harness-v2.0.0-direct-first-plan.md`）。
