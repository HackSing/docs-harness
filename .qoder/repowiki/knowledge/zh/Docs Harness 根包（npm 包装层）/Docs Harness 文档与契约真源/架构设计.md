该模块为纯文档型 leaf，按职责划分为四类文件：`architecture.md` 记录控制器真源（`scripts/harness.py`）、规则快照来源、Git/非 Git Runtime 状态边界与事实来源清单；`contracts.md` 以 v1.6.8 版本号完整定义 task-package/v2、evidence-receipt/v2、context/authorization receipt、Git 状态合同、工作区漂移归因、后台 Job 双通道、文档路由、退出码等对外契约；`testing.md` 规定 npm 脚本入口与源码层、临时项目层、后台控制面、工作量/文档路由/安装升级/下游等多层验收范围；`todo.md` 采用「先方案后条目」治理原则，仅记录状态、影响、结果与版本说明。`plans/` 目录按版本或主题存放独立方案文档（如 v1.4/v1.6.x 系列、任务准入效率、知识引导升级等），作为 TODO 条目的唯一引用来源；`reviews/` 目录集中保存 Claude Code 的代码审查输出，与 plans 并列作为变更审计依据。依赖方向单向向外：所有文档引用 `scripts/harness.py`、`package.json`、`SKILL.md` 等真实实现文件，不反向依赖代码。
